# 🛵 KargoCI — Application de Livraison de Colis

> La solution rapide pour envoyer vos colis partout en Côte d'Ivoire.

## Démarrage rapide

```bash
npx serve .
# Ouvrir http://localhost:3000
```

Ou simplement ouvrir `index.html` dans un navigateur.

## Écrans

| Écran | Route |
|---|---|
| Splash | Écran d'accueil |
| Inscription | Google / Facebook / +225 |
| OTP | Vérification SMS |
| Accueil | Dashboard utilisateur |
| Nouvelle Commande | Créer une livraison |
| Suivi | Tracking en temps réel |
| Validation | Code sécurité / QR |
| Profil | Solde & paiements |
| Historique | Courses passées |
| Livreur | Dashboard livreur |
| Admin | Tableau de bord admin |

## Stack

- React 18 (CDN)
- CSS-in-JS
- Google Fonts: Plus Jakarta Sans + Barlow
- SVG illustrations (scooter, carte Abidjan)
